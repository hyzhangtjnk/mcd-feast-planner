## 项目背景与解决的痛点

朋友聚会或同事拼单吃麦当劳，最头疼的往往不是吃什么，而是**每个人的限制完全不同**：

- **减脂控卡**：想吃汉堡又怕热量超标，必须控卡在 600 千卡以内，还要保证 25 克以上的蛋白质。
- **忌口冲突**：有人不吃牛肉，但最划算的「1+1 随心配」默认主食偏偏是双层吉士汉堡；有人吃素，有人一口辣都不能碰。
- **算账尴尬**：吃完 AA 分摊，总价除以人数经常除不尽，每次算账都得有人手动补差价或者四舍五入对不上。

**「麦麦攒局」** 将这套凑单核算流程交由算法自动化求解：
通过麦当劳官方开放平台 MCP 获取真实菜单与权威价格，由本地确定性算法在秒级时间内完成多约束组合求解。
既能满足每个人的忌口与热量目标，又能保住套餐优惠，最后还能输出一份精确到分、毫无差错的 AA 分摊账单。

> **为什么坚持「算术不进大模型」？**  
> 大语言模型擅长理解自然语言意图，但在多约束穷举、组合优化和金额精算上极易产生数字幻觉。  
> 本项目由 LLM 处理用户偏好交互，所有菜单过滤、换件判定、热量核算与 AA 分摊均由本地 Python 纯函数完成。方案完全可复现，金额严格精确到分。

## 核心能力与特色

### 1. 科学减脂控卡与能量计算
- **自然语言热量目标**：支持在参与者中直接输入 `我:减脂`（自动设定 650 kcal 上限）、`小李:高蛋白`（设定 30g 蛋白质下限），或精确指定 `maxcal=550,protein=35`。
- **多策略择优**：一次求解同时输出三套可执行方案：
  - **性价比最优**：在预算内寻求最高饱腹感与最低支出；
  - **轻负担健康版**：在可核验营养的组合中，优选平均热量最低、蛋白质供能比最高的搭配（如板烧鸡腿堡配玉米杯与无糖红茶）；
  - **丰盛豪华版**：在预算范围内吃得最满足的多元组合。
- **营养数据拒绝作假**：官方菜单中若某些餐品缺失热量数据，系统**绝不按 0 千卡计算**，而是显式标注 `⚠ 含营养数据缺失项，热量不可保证`。控卡用户的候选池绝不纳入未经核验的餐品，杜绝「伪健康」漏网。

### 2. 58 款套餐智能「换件」救单（核心差异化）
麦当劳菜单中，多达 58 款套餐支持多选区换件（`rounds[].choices[]`）。
- **痛点场景**：14.9 元的「人气经典随心配」默认主食是双层吉士汉堡（牛肉）。不吃牛肉的人以往只能整单放弃这个优惠。
- **算法救单**：算法自动在蓝区匹配同价的「那么大鸡排」或「麦香鱼」，既保住了 1+1 的优惠价格，又满足了不吃牛的忌口。
- **判定架构**：采用「先判换件，再判名称」的设计，避免带肉类默认项的套餐在初筛时被误杀。

### 3. 隐性荤菜词库防护（0 漏网）
麦当劳有许多名称完全不带「肉」字的荤菜，常规关键词过滤极易翻车：
- 「巨无霸」是纯牛肉；
- 「不素之霸」是双层牛肉配香肠；
- 「薄皮焦香V翅」是鸡翅；
- 「酥酥多笋卷」是川香鸡肉卷。

项目构建了专用隐性荤菜穷举词表，并区分两档素食标准：
- **`vegetarian`（蛋奶素）**：排除肉、禽、鱼、海鲜，保留乳制品与蛋类（芝士、新地、拿铁等可用）；
- **`vegan`（严格纯素）**：在蛋奶素基础上进一步排除一切乳制品与蛋类。  
经 737 个真实餐品实例全量展开独立复测，忌口漏网率为 0。

### 4. 整数分精确 AA 分摊
- 彻底摒弃浮点数计算，全流程采用整数「分」记账。
- 采用余数确定性分配算法，各人应付金额相加与整单实付金额严格相等，彻底消除「除不尽少一分」的烦恼。

### 5. 单人 1+1 随心配自助（`--solo`）
一个人吃麦当劳同样好用：
- **备选看板**：清晰列出当期 1+1 随心配的红蓝选区，自动标红与个人忌口冲突的选项；
- **自选手选校验**：命令行指定组合，实时核算差价并验证合规性；
- **智能推荐**：结合个人减脂控卡目标与口味偏好（如 `prefer=咖啡`），一键推荐最优低卡组合。

### 6. 纯标准库设计，开箱即用
全套代码仅依赖 Python 标准库（`urllib`、`ssl`、`json`），无任何第三方包依赖，评审与部署无需 `pip install`。

## 快速开始

### 离线演示模式（无需 Token，30 秒跑通）

仓库内置了 107 个餐品、63 款套餐的真实接口快照，克隆后即可直接运行：

```bash
cd skills/mcd-feast-planner/scripts

# 1. 多人聚餐规划（涵盖控卡、忌口、素食）
python feast_cli.py --demo --budget 60 \
    --people "我:减脂,prefer=咖啡" "小王:不吃牛,不要辣" "小张:素食"

# 2. 单人 1+1 随心配看板（查看冲突标注）
python feast_cli.py --demo --solo --me "我:不吃牛"

# 3. 单人 1+1 自选手选校验与差价试算（以人气经典随心配为例）
python feast_cli.py --demo --solo --meal 9900013304 --me "我:不吃牛" \
    --pick "蓝区=521816,粉区=3050"

# 4. 单人 1+1 控卡与口味自动推荐
python feast_cli.py --demo --solo --me "我:减脂,prefer=咖啡" --solo-recommend

# 5. 运行全量离线自动化测试套件（204 条断言）
python selftest.py
```

### 真实 MCP 模式（连接麦当劳开放平台）

在 [麦当劳开放平台](https://open.mcd.cn/mcp) 申请开发者 Token 后即可调用线上接口：

```bash
# 设置环境变量（Linux / macOS）
export MCD_MCP_TOKEN=你的Token
# Windows PowerShell
$env:MCD_MCP_TOKEN="你的Token"

# 真实门店多人点餐规划
python feast_cli.py --city "上海市" --keyword "人民广场" --budget 50 \
    --people "我:减脂,protein=25" "小王:不吃牛"
```

## 参与者描述语法速查

| 输入示例 | 解析效果 | 适用场景 |
|---|---|---|
| `"小王"` | 无限制 | 普通食客 |
| `"我:减脂"` / `"我:控卡"` | 限制热量 ≤ 650 kcal | 减脂期、控卡人群 |
| `"小李:高蛋白"` | 限制蛋白质 ≥ 30 g | 健身增肌人群 |
| `"教练:maxcal=500,protein=35"` | 精确热量上限与蛋白下限 | 严格备赛、定制饮食计划 |
| `"小王:不吃牛,不要辣"` | 自动映射内置忌口词库 | 常见饮食禁忌 |
| `"小张:素食"` | 蛋奶素模式（保留乳品与蛋） | 蛋奶素食者 |
| `"小赵:纯素"` | 纯素模式（排除一切动物制品） | 严格素食者 |
| `"我:prefer=拿铁,咖啡"` | 换件与多解择优时优先选中 | 个人风味偏好 |

内置忌口标识：`no_beef`、`no_pork`、`no_chicken`、`no_fish`、`no_seafood`、`no_fried`、`no_dairy`、`no_spicy`、`vegetarian`、`vegan`。

## 麦当劳 MCP 接入流程

```text
[1] query-nearby-stores      根据城市与地标定位门店，获取 storeCode 与 beCode
[2] query-meals              拉取门店可用餐品编码与分类标签
[3] query-meal-detail        批量拉取餐品名称、组成与 rounds[].choices[] 换件结构
    list-nutrition-foods     拉取官方全量食品营养素明细表（千卡/蛋白质/脂肪/钠等）
    calculate-price          补充核算未标价餐品的基准价格
[4] 本地确定性求解引擎         执行多约束组合搜索、忌口过滤、换件救单与 AA 分摊
[5] calculate-price          提交最终组合方案至官方接口，完成权威核价校验
```

深入踩坑与协议细节详见 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)（含真实调用的 7 大核心踩坑与规避实践）。
